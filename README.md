# PF2e Rule Element Forge

Builds a proper form for every pf2e rule element, right on the item sheet's
Rules tab — no more hand-writing raw JSON to make a rule work.

## Install

**The easy way (Windows):** download the SpazzMods installer
(https://github.com/Spazzletopia-Studios/spazzmods-installer/releases/latest),
run it, and click Install on PF2e Rule Element Forge. No account needed.

**Without the installer:** paste this into Foundry's **Install Module →
Manifest URL** box:
`https://github.com/Spazzletopia-Studios/pf2e-rule-element-forge/releases/latest/download/module.json`

## Using it

- Open any item's **Rules** tab and click the wand icon next to a rule, or
  next to **New**.
- Get a real form for whatever rule element you picked, with every field it
  actually takes, instead of a raw JSON box.
- Build predicates (the conditions that gate a rule) with a row-by-row
  builder instead of hand-written logic.
- Your draft is checked as you edit, so **Apply** stays disabled until the
  rule is valid.
- Search the compendiums for a real item using the same rule element and
  load it as a starting point.
