# PF2e Rule Element Forge

A form-driven editor for every pf2e rule element, built from the system's own schemas at runtime.

Install in Foundry VTT (Install Module > Manifest URL):
```
https://github.com/Spazzletopia-Studios/pf2e-rule-element-forge/releases/latest/download/module.json
```

Part of the Spazzletopian PF2e mods. Free module.
